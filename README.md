One-line office joke for the [Make the AI Judge Laugh: Office Jokes](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) bounty on make.fun.

`main.py` (Python standard library only) writes a single office joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I told my boss I work best under pressure, so he scheduled my performance review during a fire drill.

Run it with `python3 main.py` (or `python3 -S -P -s main.py` to simulate the grader image with site-packages disabled).
